Lab session

A user should be able to search for flights by entering From City, To City, Departure Date, number of passengers, and travel class. The system should display available flights and allow the user to select one.


Task for trainees:

Write an effective prompt for an AI tool that will generate automation test cases for this requirement.
--------------------------------------------------------------------------------------------------------------------------
STRUCTURED PROMPT
role: Act as a QA automation engineer.
context: We are testing the search function of an online flight booking service.
instruction: Generate test cases for this requirement
input data: user enters field data for From city, To City, Departure Date, number of passengers and travel class
constraints: allow uppercase/lowercase data for text fields and numeric/date data for appropriate fields, exclude performance testing.
output: the testcases should follow proper tabular template with Test Case ID, Scenario, Steps, Test Data and Expected Result.
--------------------------------------------------------------------------------------------------------------------------
